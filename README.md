## 프로젝트 목표

C 표준 라이브러리의 `printf()` 함수를 재구현하면서, </br>
가변 인자 함수를 더 깊이 이해하고 프로그래밍 기술을 향상시키는 것입니다.

## 설명

`ft_printf()` 함수는 원래의 `printf()`와 유사하게 작동하며, 다음 변환 지정자를 처리합니다:

* `%c`: 단일 문자를 출력합니다.
* `%s`: 문자열을 출력합니다 (일반적인 C 규칙에 따름).
* `%p`: void 포인터 인수를 16진수 형식으로 출력합니다.
* `%d`: 10진수 (base 10) 숫자를 출력합니다.
* `%i`: 10진수 정수를 출력합니다.
* `%u`: 부호 없는 10진수 (base 10) 숫자를 출력합니다.
* `%x`: 16진수 (base 16) 숫자를 소문자로 출력합니다.
* `%X`: 16진수 (base 16) 숫자를 대문자로 출력합니다.
* `%%`: 퍼센트 기호(%)를 출력합니다.

## 필수 파트

* 프로젝트는 C 언어로 작성되어야 하며 Norm 규정을 준수해야 합니다.
* 프로그램은 예기치 않게 종료되어서는 안 됩니다 (예: 세그먼트 오류).
* 할당된 모든 메모리는 적절하게 해제되어야 합니다. 누수는 허용되지 않습니다.
* 소스 파일을 `-Wall`, `-Wextra`, `-Werror` 플래그를 사용하여 컴파일하는 Makefile을 포함해야 합니다.
* Makefile은 반드시 `$(NAME)`, `all`, `clean`, `fclean`, `re` 규칙을 포함해야 합니다.
* `libft`를 사용하는 경우, 해당 소스 파일과 Makefile을 `libft` 폴더에 포함해야 하며, 프로젝트의 Makefile은 해당 Makefile을 사용하여 라이브러리를 컴파일해야 합니다.
* 라이브러리 `libftprintf.a`는 `ar` 명령을 사용하여 생성해야 합니다 (libtool 사용 금지).

## 보너스 파트

* 플래그: `-`, `0`, `.`, 그리고 필드 최소 너비를 처리합니다.
* 플래그: `#`, `+`, 그리고 ` ` (공백)을 처리합니다.

## 컴파일

프로젝트를 컴파일하려면 다음 명령을 사용하세요:

```bash
make bonus
````

이 명령은 `libftprintf.a` 라이브러리를 생성합니다.

## 사용법

`ft_printf()` 함수를 사용하려면 `ft_printf.h` 헤더 파일을 포함하고 `libftprintf.a` 라이브러리를 링크하세요.
